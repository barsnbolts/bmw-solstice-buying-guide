# BMW drivetrain buying guide

North American BMW engine, automatic transmission and donor research for a Pontiac Solstice race-car project.

The site is a dated research snapshot. Prices, availability, mileage, contents and condition require seller verification. No automatic stock feed or seller messaging is connected.

- Open the GitHub Pages website for the interactive report.
- Download BMW-Listings.csv for reusable listing data.
- Download BMW-Research-Pack.zip for the HTML, written findings and detailed evidence.

Original market evidence: 25 September 2026. Classified follow-up: 26 September 2026. Unknowns and historical/search-only evidence are explicitly labelled.

Changes committed to `main` are published at the same Pages URL. Downloaded files remain snapshots.
